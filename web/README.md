# Web UI — Research Workbench

Next.js 16 + TypeScript + Tailwind.

## Dev

```bash
npm install
npm run dev   # http://127.0.0.1:3000
```

Backend must be running at `http://127.0.0.1:8000` (see `../server.py` or `../run.ps1`).

Env: `NEXT_PUBLIC_API_URL` (default `http://127.0.0.1:8000`).

## Build

```bash
npm run build
npm run start
```
